# Lesson 19 — Projects

Build projects after learning each major layer.

## Project 1 — Calculator
Concepts: input, operators, conditions, methods.

Features: add, subtract, multiply, divide, remainder, repeat menu.

## Project 2 — Student Grade Manager
Concepts: arrays, methods, conditions.

Features: enter marks, total, average, grade, highest and lowest.

## Project 3 — Expense Tracker
Concepts: classes, collections, methods.

Features: add expense, list expenses, category totals, monthly summary.

## Project 4 — Library Management System
Concepts: OOP, collections, exceptions.

Features: books, members, issue/return, search, validation.

## Project 5 — JDBC Student Management System
Concepts: OOP, JDBC, SQL, CRUD and transactions.

Features: add, update, delete, search and report generation.

## Project rules
Every project should have:
- README with requirements
- Clear package structure
- Meaningful class and method names
- Input validation
- Exception handling
- Test cases
- Sample input/output
- Refactoring notes

## Capstone
Combine OOP + Collections + File I/O + JDBC + Streams to create a small **Student Course Management System**.
