# Lesson 18 — DSA Practice in Java

## Goal
Build problem-solving ability, not just Java syntax knowledge.

## Phase 1 — Fundamentals
- Complexity basics: Big-O
- Arrays and strings
- Two pointers
- Sliding window
- Prefix sums
- Hashing

## Phase 2 — Core data structures
- Linked lists
- Stack
- Queue
- Deque
- HashMap / HashSet
- Trees and binary search trees
- Heap / priority queue
- Graphs

## Phase 3 — Algorithms
- Linear and binary search
- Sorting
- Recursion and backtracking
- Greedy algorithms
- Dynamic programming
- BFS / DFS

## Beginner problem set
1. Two Sum
2. Reverse an array
3. Maximum element
4. Remove duplicates
5. Move zeroes
6. Valid palindrome
7. Anagram check
8. Frequency counter
9. Binary search
10. Merge sorted arrays

## Intermediate problem set
11. Longest substring without repeating characters
12. Maximum subarray
13. Valid parentheses
14. Merge intervals
15. Top K frequent elements
16. Reverse linked list
17. Detect cycle
18. Binary tree traversal
19. Number of islands
20. Coin change

## Practice method
For every problem: understand → write brute force → analyze complexity → improve → code → test edge cases → explain aloud.
