# Java Basics — Practice Set 1

## Level 1: Recall
1. What is Java?
2. What does JVM stand for?
3. What does JDK provide?
4. What is bytecode?
5. What is the purpose of `main`?

## Level 2: Coding
6. Print `Hello Java`.
7. Print your name, age and goal on separate lines.
8. Print a simple five-line ASCII box.
9. Create a program with two methods and call both.
10. Accept a name through command-line arguments and greet the user.

## Level 3: Debugging
Fix each program.

### Problem A
```java
public class Demo {
    public static void main(String[] args) {
        System.out.println("Hello")
    }
}
```

### Problem B
```java
public class Demo {
    public static void main(String[] args) {
        System.out.println(name);
    }
}
}
```

### Problem C
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```
Save it with a file name that matches the public class name.

## Challenge
Create `CourseIntro.java` that:
- prints a welcome message;
- prints the course name;
- prints three learning goals;
- contains one reusable method for printing a separator;
- uses clean naming and indentation.

## Self-check
Before moving to the next module, the student should be able to explain the path from `.java` source to JVM execution, identify the role of JDK/JVM, write a class with `main`, and compile/run a program without copying the commands blindly.
