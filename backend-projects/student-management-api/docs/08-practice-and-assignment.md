# 08 - Practice and Assignment

## Level 1 - Beginner

1. Add 5 students.
2. Fetch all students.
3. Fetch student by ID.
4. Update one student.
5. Delete one student.

## Level 2 - Intermediate

1. Add validation for name, email and course.
2. Create a custom `StudentNotFoundException`.
3. Add global exception handling.
4. Add search by name.
5. Add sorting by name.

## Level 3 - Advanced

1. Add DTOs.
2. Add pagination.
3. Add PostgreSQL/MySQL.
4. Add Swagger/OpenAPI.
5. Add authentication.
6. Add role-based authorization.

## Final Assignment

Build version 2 of this API with:

- Student DTO
- Validation
- Custom exceptions
- Global exception handler
- Search by name and course
- Pagination
- Unit/integration tests
- Production database configuration
